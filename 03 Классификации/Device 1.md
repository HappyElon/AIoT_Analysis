# Device 1

> [!abstract] Кратко
> Самый простой тип A-IoT устройства: отражает чужую несущую, не усиливает сигнал и не генерирует свой, питается от собранной радиоэнергии через конденсатор. Это единственный тип, по которому в Rel-19 уже написаны нормативные спецификации.

| Уровень                  | Документ                                                                                                    |
| ------------------------ | ----------------------------------------------------------------------------------------------------------- |
| Определение              | [[TR 38.769]], раздел [[38769-k00.pdf#page=52&selection=45,0,50,20\|5.1]]                                   |
| Нормативные спецификации | Rel-19, рабочий пункт RP-243326: TS 38.291 (физуровень), TS 38.391 (MAC), TS 38.191 (радиочасть устройства) |
| Сервисные требования     | [[TS 22.369]] (общие для всех типов)                                                                        |
| Класс в TR 38.848        | A или B → [[Классы A B C]]                                                                                  |
| Класс у Famaey           | UP → [[Классы UP DB DP CO]]                                                                                 |

## Радио и протокол
- Спектр: FDD FR1, пример n8 – [[38769-k00.pdf#page=186&selection=105,0,105,84|6.7.1.1]].
- Приём: OOK, без FEC ([[38769-k00.pdf#page=67&selection=101,0,105,22|6.1.1.3.1]]). Передача: Manchester+свёрточный код ([[38769-k00.pdf#page=77&selection=134,0,140,108|6.1.2.3.1]], [[State_of_the_Art_Overview_of_3GPP_Ambient_IoT_Radio_Access_Aspects.pdf#page=3&selection=44,0,44,50|Shen, с. 3]]).
- Доступ: [[Протоколы случайного доступа]], [[FDMA и малый сдвиг частоты]].
- Стек: только PHY + MAC → [[Протокольный стек]].
- Только по запросу сети: трафик DT и DO-DTT ([[38769-k00.pdf#page=12&selection=100,0,102,51|1 Scope]]).
