# Классы A, B, C (TR 38.848, Rel-18)

> [!abstract] Кратко
> Первая классификация 3GPP из исследования осуществимости [[TR 38.848]]. Классы заданы качественно: по наличию накопителя и способу передачи. Позже её заменили более детальные типы [[TR 38.769]].

| Класс | Накопитель | Свой сигнал | Передача | Цель по потреблению |
|---|:---:|:---:|---|---|
| **A** | ✗ | ✗ | отражение | ≤ 1 или ≤ 10 мкВт |
| **B** | ✓ | ✗ | отражение, возможно усиление | между A и C |
| **C** | ✓ | ✓ | активный передатчик | ≤ 1 … ≤ 10 мВт |

Классы – [[38848-i00.pdf#page=16&selection=88,0,91,21|4.3]], цели по потреблению – [[38848-i00.pdf#page=17&selection=12,0,18,11|5.1]].

Используется в [[Qu 2024 - Ambient IoT in Rel-19 Survey]].
