# Device 2a

> [!abstract] Кратко
> Передаёт сигнал отражением внешней несущей, но с усилением: отражательный усилитель или LNA. За это платит потреблением в сотни мкВт и получает дальность больше, чем у [[Device 1]]. Существует только как тип в исследовании, нормативной работы по нему нет.

## Чем задан
| Уровень | Документ |
|---|---|
| Определение | [[TR 38.769]], раздел [[38769-k00.pdf#page=53&selection=29,0,31,33\|5.2.1]] |
| Нормативные спецификации | нет: в планах нормативной работы Rel-19/Rel-20 не упоминается |
| Сервисные требования | [[TS 22.369]] (общие для всех типов) |
| Класс в TR 38.848 | B → [[Классы A B C]] |
| Класс у Famaey | DB → [[Классы UP DB DP CO]] |

## Устройство
| | |
|---|---|
| Потребление | сотни мкВт ([[38769-k00.pdf#page=53&selection=20,0,27,20\|5.2]]) |
| Питание | сборщик энергии, накопитель (конденсатор) |
| Приёмник | детектор огибающей + усилитель НЧ, компаратор или N-битный АЦП ([[38769-k00.pdf#page=53&selection=29,0,31,33\|5.2.1]]) |
| Передатчик | отражение внешней несущей |
| Усиление | **отражательный усилитель или LNA**, усиливается хотя бы одно направление ([[38769-k00.pdf#page=53&selection=29,0,31,33\|5.2.1]], [[38769-k00.pdf#page=54&selection=86,0,88,20\|5.2.1.1]]) |
| Сдвиг частоты | возможен на десятки МГц, из DL FDD в UL FDD ([[38769-k00.pdf#page=55&selection=44,0,46,23\|5.2.1.2]]) |
| Генератор | уход частоты до 10⁴ ppm ([[State_of_the_Art_Overview_of_3GPP_Ambient_IoT_Radio_Access_Aspects.pdf#page=2&selection=38,0,38,35\|Shen, с. 2]]) |
| Чувствительность | по Shen около −45 дБм ([[State_of_the_Art_Overview_of_3GPP_Ambient_IoT_Radio_Access_Aspects.pdf#page=4&selection=26,0,26,40\|Shen, с. 4]]) |
