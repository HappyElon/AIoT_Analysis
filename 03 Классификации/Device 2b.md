# Device 2b

> [!abstract] Кратко
> Первый тип с собственным передатчиком: генерирует несущую сам, без внешнего источника. Потребление сохраняется на уровне сотен мкВт. Генератор после калибровки точнее, чем у отражающих типов, поэтому частотное разделение достигается прямой модуляцией своей несущей. Нормативная работа идёт во второй фазе Rel-20.

## Устройство
| | |
|---|---|
| Потребление | сотни мкВт ([[38769-k00.pdf#page=55&selection=119,0,123,34\|5.2.2]]) |
| Питание | накопитель, сборщик энергии от радио, света, вибрации, тепла |
