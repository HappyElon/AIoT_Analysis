# IEEE 802.11bp – безбатарейный Wi-Fi

> [!abstract] О чём стандарт
> Поправка к IEEE 802.11 (Ambient Power Communication, AMP). Она меняет MAC и PHY Wi-Fi так, чтобы в сети могли работать станции, питающиеся от собранной энергии. Решает ту же задачу, что 3GPP A-IoT, но в нелицензированном спектре и с точкой доступа Wi-Fi в роли считывателя. Параллельная 3GPP ветка.

| | |
|---|---|
| Организация | IEEE 802.11, Task Group bp (TGbp) |
| Тип | поправка (amendment) к IEEE 802.11 |
| Статус | черновик, D1.0 выходит на первое голосование рабочей группы в сентябре 2026 |
| Ожидаемое утверждение | май 2028 (прогноз IEEE 802.11) |
| Роль для A-IoT | альтернативный трек в нелицензированном спектре |

## История и сроки
| Когда | Этап |
|---|---|
| мар 2023 | Topic Interest Group AMP завершила технический отчёт о применимости ambient power в 802.11 |
| 2023–2024 | Study Group AMP готовит PAR (рамки проекта) и CSD |
| 21 мар 2024 | утверждён PAR P802.11bp, создана TGbp |
| янв 2026 | черновик D0.2, дальше доработка по PDT-предложениям |
| июл 2026 | демонстрация на заседании: точка доступа Wi-Fi обменивается данными с AMP-меткой, запитанной только её радиосигналом |
| сен 2026 | D1.0 – первое голосование рабочей группы (WG letter ballot) |
| май 2028 | ожидаемое утверждение стандарта |

## Что определяет (по PAR)
- Изменения MAC и PHY для AMP-станции с питанием от сбора энергии.
- Минимум один режим передачи данных в sub-1 ГГц.
- Минимум один режим в 2,4 ГГц; трафик AMP идёт с категорией доступа AC_BK (фоновая), чтобы не мешать обычным станциям.

## Ключевые параметры
По [[Famaey 2026 - Survey on Ambient IoT]] ([[nbnfioulu-202609045969.pdf#page=9&selection=17,0,17,54|Famaey, с. 9]]):

| Параметр | Значение |
|---|---|
| Скорость | около 250 кбит/с и 1 Мбит/с |
| Диапазоны | sub-1 ГГц и 2,4 ГГц |
| Считыватель | точка доступа Wi-Fi |

## Сравнение с 3GPP A-IoT
| | IEEE 802.11bp | 3GPP A-IoT |
|---|---|---|
| Спектр | нелицензированный: sub-1 ГГц, 2,4 ГГц | лицензированный FDD FR1 оператора → [[TR 38.769]] |
| Считыватель | точка доступа Wi-Fi | базовая станция или смартфон |
| Статус | черновик, утверждение ожидается в 2028 | Rel-19 заморожен, Rel-20 в работе |
