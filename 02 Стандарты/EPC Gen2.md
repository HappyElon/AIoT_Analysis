# EPC Gen2 (UHF RFID)

> [!abstract] О чём стандарт
> Протокол радиоинтерфейса для пассивных UHF RFID-меток, который разработал EPCglobal (GS1). Он описывает, как считыватель запитывает метки своим полем, опрашивает их и разбирает коллизии, когда отвечают сразу несколько. Это прямой предок Ambient IoT: оттуда взяты backscatter, ориентир по сложности и схема случайного доступа.

|                |                                                                                  |
| -------------- | -------------------------------------------------------------------------------- |
| Организация    | EPCglobal (GS1), затем ISO/IEC                                                   |
| Тип            | отраслевой стандарт радиоинтерфейса                                              |
| Принят         | 2004, позже ISO/IEC 18000-6C (ныне 18000-63)                                     |
| Роль для A-IoT | ориентир сложности класса A в [[TR 38.848]], основа процедуры случайного доступа |

## Ключевые параметры
| Параметр | Значение |
|---|---|
| Диапазон | 860–960 МГц; в РФ для RFID – 866–868 МГц (проверить по решениям ГКРЧ) |
| Множественный доступ | кадровая ALOHA, размер кадра 2^Q, Q-алгоритм |
| Обмен | RN16 (16-битный случайный номер) → ACK → EPC; похоже на Msg1/Msg2/Msg3 в A-IoT |
| Ответ метки | на поднесущей Miller; все метки на одной, частотного разделения нет |
| Чувствительность чипа | порядка −20…−25 дБм |
| Дальность | 5–15 м |
